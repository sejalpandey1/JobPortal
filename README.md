JobsIndia – Job Portal Android App

A full-featured Job Portal Android Application developed using Java, XML, and Firebase, designed to connect job seekers with employers through a modern and user-friendly mobile platform.

📱 Project Overview

JobsIndia is an Android-based job portal that provides separate experiences for Job Seekers and Employers.

Job seekers can discover and apply for jobs, manage their profiles and resumes, communicate with employers, and track applications. Employers can post and manage job openings, review applicants, manage hiring processes, and communicate with candidates.

The application is organized into separate modules for:

- Job Seekers
- Employers
- Admin Management
- Job Management

- Real-Time Chat

📄 Resume Builder

The application includes a Resume Builder that allows users to create professional resumes by entering their personal, educational, technical, and professional information.

The generated resume can be saved as a PDF and shared with potential employers.

🔥 Firebase Integration

Firebase is used throughout the application for:

- Authentication
- User & job data management
- Resume/file storage
- Real-time application updates
- Chat functionality
- Push notifications

🚀 Getting Started

Prerequisites

- Android Studio
- Android SDK
- Java / JDK
- A Firebase project

Setup

1. Clone this repository.
2. Open the project in Android Studio.
3. Create/configure your own Firebase project.
4. Add your Firebase Android configuration file inside the "app/" directory.
5. Sync Gradle.
6. Build and run the application.

🔐 Security Note

API keys, Firebase configuration files, local configuration files, and other sensitive credentials are not included in this repository.

🎯 Project Objective

The main objective of this project is to develop a complete mobile-based recruitment platform that simplifies the process of job searching, job posting, applications, resume management, and communication between job seekers and employers.
